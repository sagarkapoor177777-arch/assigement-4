# 📊 Assignment 4 – Data Cleaning, EDA & Power BI Dashboard

## 📌 Project Overview

This project is **Assignment 4**, focused on the complete data analysis workflow using **Python, Pandas, and Power BI**.

For this project, I worked with a sample dataset and performed **data cleaning, data preprocessing, and Exploratory Data Analysis (EDA)** using Python and Pandas. After preparing and analyzing the data, I created an interactive **Power BI dashboard** to visualize important insights and trends.

The main objective of this assignment was to understand how raw data can be transformed into meaningful insights through data analysis and visualization.
